Sistema de Biblioteca

Sistema desenvolvido como projeto acadêmico utilizando Java, Spring Boot e Maven.

Objetivo

Desenvolver um sistema de biblioteca que permita o cadastro de usuários, publicação de livros por escritores e empréstimo e devolução de livros por leitores.

Tecnologias utilizadas

Java

Spring Boot

Maven

HTML

CSS

JavaScript

Funcionalidades

Cadastro e autenticação

Cadastro de usuários

Login de usuários

Gerenciamento de livros

Cadastro de livros

Edição de livros

Exclusão de livros

Listagem completa de livros

Empréstimos

Realizar empréstimo de livros

Devolver livros
